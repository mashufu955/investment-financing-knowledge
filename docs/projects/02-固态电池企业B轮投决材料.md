# 固态电池企业B轮投决材料

项目：清能固态电池
行业：新能源
轮次：B轮
地区：宁波
阶段：investment_committee

融资概况：3亿 CNY，投后估值 30亿 CNY。

业务概要：
公司主营半固态/全固态锂电池，能量密度达 450Wh/kg，已向两家头部新势力车企送样验证。一期产线 1GWh 已建成，二期规划 5GWh。团队源自中科院物理所，核心专利 28 项。

财务要点：
2024 年小批量出货营收约 8000 万元，单位成本高于液态电池 40%，预计量产后降至 1.2 倍以内。本轮资金用于 5GWh 产线建设与原材料备货。

风险点：固态电解质供应链尚未成熟，规模化良率待验证；整车验证周期 12-18 个月。
相关方：创始人团队 45%，A 轮股东 20%，本轮领投拟占 10%。
