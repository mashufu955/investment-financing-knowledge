# 储能科技公司A轮尽调

项目：熙能储能科技
行业：新能源
轮次：A轮
地区：常州
阶段：due_diligence

融资概况：2亿 CNY，投前估值 8亿 CNY。

业务概要：
公司主营工商业储能系统集成，自研 314Ah 储能电芯与液冷 PCS，系统循环效率 92%。已交付项目 25 个，累计装机 1.2GWh。团队来自宁德时代与阳光电源，核心 60 人。

财务要点：
2024 年营收 4.5 亿元，毛利率 14%，订单储备达 3GWh。本轮资金用于电芯产线扩建与海外渠道建设。

风险点：电芯价格波动压缩集成毛利；海外项目回款周期长。
相关方：创始团队 55%，天使轮股东 12%，本轮领投拟占 10%。
