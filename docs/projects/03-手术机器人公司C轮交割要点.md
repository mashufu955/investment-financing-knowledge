# 手术机器人公司C轮交割要点

项目：精微医疗手术机器人
行业：医疗器械
轮次：C轮
地区：深圳
阶段：closing

融资概况：5亿 CNY，投后估值 50亿 CNY。

业务概要：
公司主攻腔镜手术机器人，已取得 NMPA 三类证并完成 1200 例临床手术。产品部署 40 家三甲医院，耗材复购收入占比 35%。海外通过 CE 认证，已进入欧洲 5 国市场。

交割要点：
优先清算权 1 倍；反稀释加权平均；创始人 4 年服务期锁定；董事会 7 席我方占 2 席。交割前置条件：知识产权尽调无重大瑕疵、关键研发人员竞业协议签署完毕。

风险点：达芬奇国产替代竞争加剧；耗材集采可能压缩毛利。
相关方：创始团队 38%，B 轮及之前股东 30%，本轮联合投资方拟占 10%。
